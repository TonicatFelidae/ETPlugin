***ETClaimEffect Quick Guide*** 

--ET means enchanted technology :D sounds cool right???--

Modified value in ETClaimEffectMain to achieve desired results;
To change claimable value => edit protocolDatas.
To change particle efect=> edit RewardParticleSetting (you can also modified the particle itself).

ETClaimEffect's principles:
- If you need to claim 110 resources, with the coincost = 53, you will have 3 particle, first two have value of 53 and the last one is 4;
- Value in your resource bar will increase when the particle reach its destination.
