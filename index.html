ET Plugin UPM Scoped Registry

Add this Scoped Registry to your Unity project's Packages/manifest.json to browse and install all ET packages directly inside Window → Package Manager → My Registries:

"scopedRegistries": [
  {
    "name": "ET Plugin Registry",
    "url": "https://tonicatfelidae.github.io/ETPlugin",
    "scopes": [
      "com.nekoniiistudio.et"
    ]
  }
]
